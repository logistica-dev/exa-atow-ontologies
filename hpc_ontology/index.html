Ontology Specification Draft

Abstract

The HPC Resource Ontology is a semantic framework designed to model and manage the complex landscape of High-Performance Computing (HPC) infrastructure. As national computing centers increasingly diversify their architectures—integrating heterogeneous compute nodes, multi-layered storage systems, and specialized accelerators—standardizing the representation of these resources becomes critical. This ontology provides a structured, machine-readable model of HPC hardware, software environments, and administrative configurations. It enables interoperability, automated resource discovery, and intelligent querying across disparate HPC centers, ultimately facilitating more efficient resource utilization and analysis.

Introduction back to ToC

Modern HPC systems have evolved into intricate ecosystems characterized by a wide array of processor architectures, specialized hardware accelerators, and high-performance parallel file systems. Managing information about these resources is often hampered by silos, as documentation is frequently scattered across disparate web pages, wikis, and configuration files, often in inconsistent formats. The HPC Ontology project aims to bridge this gap. By mapping the relationships between physical components, logical partitions, and software stacks, it creates a unified knowledge graph of national-scale HPC resources. This project provides a foundation for developers and researchers to query system capabilities, track infrastructure evolution, and automate the synchronization of hardware specifications across national computing centers.

HPC Resource Ontology: Description back to ToC

Ontology for modeling high-performance computing resources, infrastructure, and physical characteristics. This ontology describes the physical and logical components that constitute HPC systems, including compute nodes, processors, storage, interconnects, and their relationships. It supports the modeling of supercomputer architectures, partitions, and execution environments, with a focus on French national HPC centers (IDRIS/Jean Zay, CEA/TGCC, Cines/Adastra, GRICAD). It is published as two modules sharing ONE namespace (https://w3id.org/Exa-AToW/hpc#): hpc-core.ttl (https://w3id.org/Exa-AToW/hpc/hpc-core.ttl) holds the minimal physical and hardware vocabulary; hpc.ttl (https://w3id.org/Exa-AToW/hpc/hpc.ttl) imports the core and adds infrastructure, interconnects, software, file systems, scheduling policy and organizations. To use only the basics, add owl:imports . To use everything, add owl:imports (the core is imported transitively). Each term carries rdfs:isDefinedBy indicating its module.
